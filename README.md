# fader
simple fader script for macos using applescript

Usage: fader [starting volume] [ending volume] [seconds between steps] [in/out]

What it does
  fader changes your volume. it's very simple to use
  
  the [starting volume] value is the starting volume of the fade
  
  the [ending volume] value is the ending volume of the fade 
  
  the [seconds between steps] value is how long to wait in seconds between steps down. steps are 5% at a time.
  
  the [in/out] value is either in or out.

  if you put the letter "h" in the 1st variable spot it echos the usage message at the top of this document. it will result in an error, but it doesn't cause any problems so don't worry about it.
